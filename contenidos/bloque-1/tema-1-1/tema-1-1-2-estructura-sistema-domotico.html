Comprende

Un sistema no es una colección de dispositivos

Los componentes adquieren sentido cuando existe una relación funcional clara entre lo que ocurre en el entorno, la decisión del sistema y la respuesta ejecutada.

Pregunta detonante

Si colocamos un sensor de movimiento, una lámpara inteligente y una aplicación móvil en una habitación, ¿tenemos automáticamente un sistema domótico? ¿Qué conexión funcional tendría que existir entre ellos?

Estructura

Cinco funciones básicas

Los productos concretos pueden cambiar, pero estas funciones aparecen una y otra vez en sistemas de automatización.

Sensores

Captan información del entorno: movimiento, temperatura, apertura, luz, humo, humedad, etc.

Controladores

Procesan información y aplican reglas para decidir qué debe ocurrir.

Actuadores

Modifican el entorno: conmutan cargas, mueven motores, regulan intensidad o activan alarmas.

Comunicación

Transporta datos y órdenes entre componentes, de forma cableada o inalámbrica.

Interfaz

Permite al usuario visualizar estados, configurar funciones o ejecutar acciones.
